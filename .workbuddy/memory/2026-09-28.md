# 2026-09-28 工作紀錄

## Toolbox 桌面應用程式（v1.0.0）初版建置完成

- **定位**：Windows 模組化桌面效率中心，主程式 + 工具市集動態下載/安裝/載入微型工具。
- **技術決策（用戶已確認）**：Electron（31.7.7）+ 純前端工具 + 受限 Tool API；測試階段先不打包 exe。
- **架構**：
  - 工具在 `<webview>` 內以 `nodeIntegration=off` + `contextIsolation=on` 執行（`webviewTag:true`）。
  - 工具只能透過 `tool-preload.js` 注入的 `window.toolbox` 呼叫白名單 API；主進程依 `manifest.json` 的 `permissions` 做最小權限驗證（webContentsId→toolId 映射防偽造）。
  - 安裝生命週期：下載→SHA256 校驗→安全解壓（防 zip-slip）→驗證 manifest/entry→原子搬移→回滾。
- **本地測試（無 GitHub）**：`app.isPackaged=false` 時清單預設指向 `dev-server/tools.json`（file://），可離線零設定測試。`TOOLBOX_MANIFEST_URL` 環境變數 > config.json > 預設。
- **已驗證**：`npm run smoke` 端到端通過（catalog→install→validate→zip-slip 攔截→uninstall）。`--smoke-window` 需真實桌面（無頭環境 GPU 崩潰屬環境限制）。

### 關鍵陷阱（重要）
- **`ELECTRON_RUN_AS_NODE=1`**：此變數在 WorkBuddy 沙盒環境被設為 1，會讓 `electron.exe` 退化成純 Node，`require('electron')` 回傳路徑字串而非 API（`app` undefined）。跑 smoke/啟動前需 `env -u ELECTRON_RUN_AS_NODE`。用戶本機終端通常無此變數。
- **AdmZip `addFile` 會正規化 `../`**：zip-slip 測試需用 raw zip 位元組手工構造（`makeRawZip`），否則測不到防護。

### 工具開發約定

- manifest 支援 name/description 為物件 `{en, zh-TW, zh-CN}` 或純字串。

### 環境限制（重要，避免重複踩坑）
- **此 WorkBuddy 執行環境無法渲染 Electron GUI**：renderer 子進程一啟動即崩潰（`render-process-gone reason:"crashed" exitCode:-2147483645` = STATUS_BREAKPOINT），GPU 進程也 access violation（0xC0000005）。這是環境對子進程注入監控鉤子所致，`dangerouslyDisableSandbox` 與 SwiftShader 軟體渲染都無效。
- 結論：在此環境**只能跑主進程邏輯**（`--smoke` 已驗證），UI 渲染需用戶在本機終端自行 `npm start`。

### 第六輪（🎉 找到真正根因 + 修復）
- **真正根因（紅字診斷立功）**：`Uncaught SyntaxError: Identifier 'api' has already been declared`。`contextBridge.exposeInMainWorld('api')` 會在 window 建立**不可配置（non-configurable）**屬性；renderer.js 的 `const api = window.api` 觸發 `HasRestrictedGlobalProperty` → SyntaxError → **整個 renderer.js 一行都不執行**。這才是歷來「按鈕全死」的元兇（CSP 只是疊加因素）。之前錯誤不可見，是因為錯誤處理器也在同一檔案內一起死；release4 把 handler 移到 head inline script 後才現形。
- **修法**：宣告改名 `api` → `bridge`（16 處呼叫全改）。**教訓：contextBridge 暴露的鍵名不可再以 const/let 宣告同名全域變數。**
- 移除紅字錯誤條（index.html head + renderer.js 都改 console-only，不顯示給使用者）。
- renderShop 錯誤改友善訊息（新 key `shop.checkConnection`，不顯示原始 err）。
